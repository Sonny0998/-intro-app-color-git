# EDHA - Éducation et Développement pour le Progrès d'Haïti

Site web officiel de EDHA (Education and Development of Haiti), une organisation non gouvernementale dédiée à l'autonomisation et au développement holistique des jeunes haïtiens.

## 🎓 À propos d'EDHA

EDHA est une organisation qui œuvre pour l'éducation et le développement en Haïti à travers :

- **Éducation et formation intégrale** : Accès à une éducation de qualité combinant connaissances académiques et compétences pratiques
- **Formation technique et professionnelle** : Programmes en technologie, entrepreneuriat, santé communautaire et métiers techniques
- **Leadership et autonomisation des jeunes** : Développement du leadership et de la responsabilité sociale
- **Développement communautaire et durabilité** : Projets dans les domaines de la santé, environnement et égalité

## 🚀 Technologies utilisées

- **Next.js 16** - Framework React pour applications web
- **React 19** - Bibliothèque JavaScript pour interfaces utilisateur
- **TypeScript** - Typage statique pour JavaScript
- **Tailwind CSS 4** - Framework CSS utilitaire
- **Poppins Font** - Police Google Fonts

## 📦 Installation

```bash
# Installer les dépendances
npm install

# Lancer le serveur de développement
npm run dev

# Compiler pour production
npm run build

# Lancer en production
npm start
```

## 🎨 Caractéristiques du site

1. **Hero** - Message principal et appel à l'action
2. **Domaines d'action** - 4 axes stratégiques d'intervention
